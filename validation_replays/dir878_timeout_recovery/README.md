# DIR-878 closure-2 high-budget recovery

This standalone evidence package records one higher-budget, identity-bound symbolic replay of a current multi-state record that previously had no replay receipt. The baseline selected record was a typed residual with an incomplete collection; the recovery completed 10/10 seed obligations and collected 160 bounded sink profiles. The recovered bounded collection observed `VECTOR_SAT` with direct sink-byte provenance.

The recovery preserves the closure index, source address, sink address, and sink function, but its concrete command/snapshot digest differs from the incomplete baseline because a later collected sink instance was materialized. The outcome change is therefore reported as an observation, not as a silent promotion of the frozen campaign classification. This is direct evidence that First-Ready or incomplete single-instance results cannot support candidate-wide negative conclusions.

| Check | Result |
|---|---:|
| Recovery receipt | 1/1 |
| Seed obligations complete | 10/10 |
| Bounded profiles | 160 |
| Candidate-wide negative flags | 0 |
| Primary observation | `RESIDUAL` -> `VECTOR_SAT` |

The package is experimental evidence only. It does not establish exhaustive sink-state coverage, solver soundness, source realizability in firmware, firmware-wide precision/recall, human ground truth, or device-level exploitability. No firmware service, shell, generated witness, network workflow, or device effect was executed. Manuscript projects were not modified.
