\begin{abstract}
Cloud-connected edge gateways inherit critical vulnerabilities directly from embedded firmware. Static analyzers scale candidate discovery across firmware archives. However, raw taint closures do not identify which bytes control the final shell command or which syntax effects remain feasible, imposing severe triage fatigue on security analysts. We present \tool, an evidence-oriented triage framework for edge-firmware warnings built around an executable \emph{final-byte evidence contract}. \tool binds sink argument semantics, reconstructs concrete C strings, tracks byte provenance, and evaluates a versioned quote-aware 11-vector shell effect matrix.

Evaluated on eight commercial router firmware images spanning \TSDSReviewCampaignRecords{} static warnings, \tool isolates \TSDSReviewCampaignCompleteDirect{} complete-string and \TSDSReviewCampaignObservedPrefixDirect{} observed-prefix injection profiles. This reduces manual triage volume by 92.3\%, while strictly preserving all \TSDSReviewCampaignResidual{} unresolved cases as explicit typed obligations. Dynamic execution under QEMU system emulation confirms that synthesized command witnesses trigger genuine shell command execution across commercial services, including Netgear, Tenda, and D-Link router firmware. In controlled counterfactual benchmarks, \tool achieves 100\% precision (=1.0$), eliminating 10 false positives from raw reachability and 5 from regex scanning, while uniquely emitting exact byte extents, quote contexts, and cryptographic audit receipts.
