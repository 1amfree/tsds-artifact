\section{System Overview}
\label{sec:overview}

Figure~\ref{fig:architecture} illustrates \tool within a cloud DevSecOps pipeline for edge firmware. Designed as an elastic, containerized cloud service, \tool ingests firmware images and static warnings from cloud registries and resolves four evidentiary gaps left unaddressed by static scanners. A digest-checked adapter binds candidate identity without inheriting front-end verdicts. Evidence search steers execution along the recovered sink corridor across distributed worker pods. A semantic plugin then resolves the callee contract and materializes the concrete command buffer to restrict matrix solving exclusively to source-controlled offsets. The ledger serializes all resulting instance profiles and open obligations under a single cryptographic identity to prevent unranked static warnings from entering cloud deployment pipelines as unverified claims.

Algorithm~\ref{alg:evidence} enforces the candidate accounting invariant: every admitted candidate produces exactly one record. \textsc{ResolveByteView} returns an admitted direct or conditioned mode, or an unresolved byte-view obligation; other search, capture, binding, provenance, or solver failures remain strictly typed. A complete direct instance with no controlled extent is classified as \nms before matrix solving. A prefix-only view can emit the weaker \psat sidecar from Eq.~\ref{eq:prefix-class}, but cannot emit complete-string \svsat, \mfilt, or \nms. Unresolved views cannot enter semantic classes. Write $\operatorname{Ready}(\kappa,B)\triangleq\operatorname{Claimable}(\kappa)\land\operatorname{CompleteCString}(B)$.

The bounded collector visits sink hits in scheduler order and retains complete Ready and prefix-only views through the configured settle window. A deterministic primary selector prefers the earliest complete positive profile, followed by the earliest complete claimable direct matrix profile. If neither exists, positive prefix sidecars are emitted strictly as \psat; otherwise, the candidate is conserved as a typed residual. No incomplete snapshot is ever promoted to complete direct evidence. In complete direct mode, a SAT cell supplies an existential witness for that modeled instance. In contrast, \mfilt and \nms remain local profiles and never authorize candidate-wide elimination. \ctsat retains the same selected-instance scope alongside the reconstruction-link gate in Eq.~\ref{eq:conditioned-evidence}. States outside the captured instance are never silently universalized: absent an admissible instance, the candidate is conserved as a static obligation or residual.

Guarded refinement synthesizes summaries exclusively for residuals. Each admitted bundle configures a bounded replay through Algorithm~\ref{alg:evidence}; the result remains conditioned and outside the primary aggregate.
